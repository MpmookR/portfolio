# Mook Rattana — Portfolio

**Live site:** [mooksportfolio.netlify.app](https://mooksportfolio.netlify.app)

I'm Puangpaka (Mook) Rattana — an MSc Software Engineering graduate working across product design and frontend engineering. I build the whole thing: scope it, design it, ship it, and write up what actually happened, including the trade-offs and shortcuts, not just the polished result.

This repo is the source for my portfolio site, organized around two lenses on the same underlying skillset:

- **Product Design & Engineering** — full-stack builds shipped end to end, from a solo freelance client project (a bilingual, CMS-driven menu system) to iOS apps with real backend infrastructure.
- **UX Design** — research-driven design work: wireframes, usability testing, and stakeholder collaboration, spanning freelance and academic projects.

Every project page is a written case study rather than a gallery: the actual problem, what got scoped out and why, engineering decisions made under real constraints, and honest outcomes.
